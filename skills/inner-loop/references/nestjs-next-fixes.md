# Recurring failures in this stack

Causes, not workarounds. Migrated from the retired `fix-and-verify` and `verify-stack` skills, which hardcoded these commands into the gate itself — the gate now comes from `.agent/loop.json`, and only the diagnosis knowledge lives here.

## TypeScript

| Symptom | Cause and fix |
|---|---|
| `strictPropertyInitialization` on a DTO field | The field is assigned by the validation pipe, not the constructor. Add `!`. Do not make it optional — that changes the API contract. |
| Prisma nullable JSON rejected | Use `?? Prisma.JsonNull` for a null write, or `as Prisma.InputJsonValue` when the value is known non-null. `undefined` means "leave unchanged", which is a different operation. |
| `findUnique` rejects `null` in a compound key | Prisma cannot use `null` in a compound unique. Use `findFirst({ where: { name, tenantId: null } })`. |
| Type error only in the monorepo, not the app | The root `tsc --noEmit` is picking up the wrong `tsconfig.json`. Point the check's `cmd` at the app's config, or set `cwd` on the check. |

## NestJS

| Symptom | Cause and fix |
|---|---|
| Transient provider resolves wrong or throws in `main.ts` | Do not call `app.get(SomeTransientService)` — a TRANSIENT provider returns a fresh instance per injection. Use singleton scope, or inject where it is actually needed. |
| CORS still blocked after editing `.env` | `@nestjs/config` validation classes carry hardcoded defaults (e.g. `http://localhost:3001`) that win over `.env`. Update the default in the class, not just the env file. |
| Test fails with "Nest can't resolve dependencies" | The test module is missing a provider the service now needs. Add it to the test module's `providers`, with a mock if it touches IO. |

## Jest / Vitest

| Symptom | Cause and fix |
|---|---|
| Mock missing a method the service now calls | Add `jest.fn()` to the mock object. A partial mock silently returns `undefined` and fails somewhere unrelated. |
| Assertion fails after a signature change | Update the expectation. Only after confirming the *new* signature is the intended one. |
| Test passes alone, fails in the suite | Shared mutable state between tests. Reset it in `beforeEach`, do not reorder tests to hide it. |
| Gate hangs and times out | The `test` script is a watcher. It needs `vitest run` or `jest --ci`, set in `.agent/loop.json`. |

## ESLint

| Symptom | Cause and fix |
|---|---|
| `no-floating-promises` | Add `await`, or prefix with `void` when fire-and-forget is genuinely intended. |
| `no-unused-vars` on a required signature parameter | Prefix with `_`. |
| `prefer-promise-reject-errors` | Reject with `new Error(...)`, never a bare string. |
| `@typescript-eslint/no-unused-expressions` firing on valid React | Known false positive in the v8 rule. Disable the rule for the web app — it is not a real error. |

## Environment (exit code 2)

| Symptom | Cause and fix |
|---|---|
| Every check fails with "cannot find module" | Dependencies are not installed. `loop` catches this before running the gate. Install first. |
| `npx <tool>` runs something unexpected | Bare `npx` downloads an unrelated package from the registry when the local binary is missing. Contracts generated by `loop init` use `npx --no` for exactly this reason. |
| Port 5432 already in use by Docker | Local Postgres is holding it. Move Docker to 5433 and update `DATABASE_URL`. |
| Turbo warns about a missing package manager | Root `package.json` needs `"packageManager": "npm@x.y.z"`. |
| `.env` values ignored in Python tooling | `load_dotenv(override=True)` — without `override`, the shell environment wins. |
